while loop concept
🔄 New superpower: while loop

Run as long as
something is true.

?

Checks a condition

while x < 10: — run while x is less than 10

🔁

Body runs again & again

Until the condition becomes False

⚠️

Must change something!

If the condition never becomes False → infinite loop 💥 (program freezes)

Roll until you get a 6
Round 1
🎲 = 3→ keep rolling
Round 2
🎲 = 1→ keep rolling
Round 3
🎲 = 5→ keep rolling
Round 4
🎲 = 6→ DONE ✓
Took 4 rolls — but we didn't know in advance!

Code · while + random
Live code · Try it!

Roll until six. 🎲

dice_roll.py
import random

dice = 0            # start with anything not 6
count = 0

while dice != 6:
    dice = random.randint(1, 6)
    count = count + 1
    print(f"Roll {count}: 🎲 = {dice}")

print(f"🎉 Got 6 after {count} rolls!")
💡 Tip != means "not equal" — loop runs while dice is NOT 6

When to use which
🆚 Both can do the same job — pick wisely

Ask yourself:
do I know the count?

for ✓

Known count

When you know how many rounds ahead of time.

for i in range(10):
  print(i)
  • ✓ Loop a list
  • ✓ Times table (1-12)
  • ✓ Print 30 students
while ⭐

Unknown count

When you stop based on a condition.

while dice != 6:
  dice = roll()
  • ✓ Roll until 6
  • ✓ Guess until correct
  • ✓ Login retry until valid
