range() full power
range(start, stop, step)

3 arguments control the whole loop

S

start — where to begin

The first number (included in the loop)

E

stop — where to end

The stopping number (NOT included!)

↗

step — jump size

+1 (default) · +2 (evens) · -1 (backwards)

NORMAL
range(1, 6) → 1, 2, 3, 4, 5
STEP=2 (EVENS)
range(0, 10, 2) → 0, 2, 4, 6, 8
STEP=-1 (BACKWARDS)
range(10, 0, -1) → 10, 9, 8 ... 1

3 ways to loop with range.

range_examples.py
# 1) Countdown — step backwards
for i in range(10, 0, -1):
    print(i)        # 10, 9, 8, ..., 1

# 2) Even numbers — skip by 2
for n in range(2, 21, 2):
    print(n)        # 2, 4, 6, ..., 20

# 3) Multiples of 5 — skip by 5
for m in range(5, 101, 5):
    print(m)        # 5, 10, 15, ..., 100
💡 Tip stop is exclusive! Want up to 20? Write range(..., 21, ...)

Code · Accumulator
Live code · Accumulator

Sum even numbers 2 to 20

even_sum.py
# Sum even numbers: 2, 4, 6, ..., 20
total = 0                           # ← start at 0

for n in range(2, 21, 2):
    total = total + n          # ← add every round
    print(f"Added {n} → total is {total}")

print(f"💰 Grand total = {total}")  # = 110
⚡ Shortcut total += n is short for total = total + n
