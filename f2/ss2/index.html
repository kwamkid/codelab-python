Index = position number
🎯 Each item has a position number

⚠️ Counting
starts at 0!

0

Forward — starts at 0

list[0] is the FIRST item, not list[1]!

−

Backward — negative index

list[-1] is the LAST. list[-2] is second-to-last.

!

Out of range = error

list[99] on a 5-item list → IndexError 💥

Code · Index
Live code · Try it!

Grab any item
by [position].

index_demo.py
fruits = ["🍎", "🍌", "🍊", "🍇"]

# Forward indexing — starts at 0!
print(fruits[0])    # 🍎  (first)
print(fruits[2])    # 🍊

# Backward indexing — negative
print(fruits[-1])   # 🍇  (last!)
print(fruits[-2])   # 🍊

# Edit by index
fruits[1] = "🍓"
print(fruits)
# ['🍎', '🍓', '🍊', '🍇']
💡 Tip list[-1] always grabs the LAST — no need to count items!

Slicing patterns
🔪 Cut a range from the list

stop is excluded! ⚠️

list[1:4]
From index 1 to 3 (4 excluded)
→ ['🍌', '🍊', '🍇']
list[:3]
From start to index 2
→ ['🍎', '🍌', '🍊']
list[2:]
From index 2 to end
→ ['🍊', '🍇', '🍉', '🍓']
list[-3:] ⭐
Last 3 items (super useful!)
→ ['🍇', '🍉', '🍓']
💡 Empty side = "from beginning" or "to the end" automatically
