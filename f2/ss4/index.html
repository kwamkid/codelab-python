List iteration
🔁 Two ways to walk a list

One is cleaner.

❌

The hard way (with index)

for i in range(len(list)):
then list[i] every time. Tiring!

✅

The Python way

for item in list:
Python hands you each item directly!

💡

Item is a temp variable

Name it anything: for friend in friends reads naturally.

friends = ["Alex", "Bob", "Cat"]
Round 1
friend = "Alex"
Round 2
friend = "Bob"
Round 3
friend = "Cat"
Done! No counting needed 🎉
for item in list — clean & pythonic 06 / 19
Thailand
Code · iteration
Live code · Try it!

Walk a list
like a pro.

friends.py
friends = ["Alex", "Bob", "Cat", "Dan"]

# ✅ The Python way
for friend in friends:
    print(f"Hi {friend}!")

# Output:
# Hi Alex!
# Hi Bob!
# Hi Cat!
# Hi Dan!
💡 Tip Variable name is your choice — use a singular word that describes one item.
