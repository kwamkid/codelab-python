Code · list operations
Live code · Try it!

Build & modify a list.

list_basics.py
# Create a list with [ ]
friends = ["Alex", "Bob", "Cat"]
print(friends)         # ['Alex', 'Bob', 'Cat']

# Add to the end
friends.append("Dan")
print(friends)         # ['Alex', 'Bob', 'Cat', 'Dan']

# Remove a specific item
friends.remove("Bob")
print(friends)         # ['Alex', 'Cat', 'Dan']

# Check if something is inside
print("Alex" in friends)  # True
print(len(friends))    # 3
💡 Tip append() adds at end · remove() takes by name · pop() takes last
