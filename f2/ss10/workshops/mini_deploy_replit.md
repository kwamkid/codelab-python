# 🌐 Mini · Deploy = เปิดร้าน!

> GitHub = เก็บโค้ด · Deploy = ทำให้คนกดเล่นได้จริง (เปิดร้านให้คนเข้า!)

## ขั้นตอน (15 นาที)

1. ไปที่ **replit.com** → Create Repl → เลือก **Import from GitHub**
2. วาง URL repo ของหนู → Import
3. กด **Run** → โปรแกรมรันบน browser
4. กด **Share** → copy **public link**
5. ส่ง link ให้เพื่อน → เปิดบนมือถือเล่นได้เลย!

> 💡 GitHub (เก็บ) + Replit (เปิดให้เล่น) = ครบวงจรเหมือน programmer จริง
