# 🖥️ W1 · GitHub = Google Drive สำหรับโค้ด

> GitHub = ที่เก็บโค้ดออนไลน์ + เก็บประวัติการแก้ไข (ใครก็เปิดดูได้!)

## ขั้นตอน (20 นาที — ครู demo สด)

1. **สมัคร GitHub** → github.com → Sign up (ใช้ email · อายุ <13 ใช้ของผู้ปกครอง)
2. **ติดตั้ง GitHub Desktop** → desktop.github.com → Download → Install → Sign in
3. **สร้าง repo แรก** → GitHub Desktop: File → New Repository
   - Name: `my-first-code`
   - กด Create Repository
4. **ใส่โค้ด** → copy ไฟล์ .py ของหนู (เช่น เกมจาก Level 1) ไปวางในโฟลเดอร์ repo
5. **Commit** → GitHub Desktop เห็นไฟล์ → ใส่ข้อความ "เพิ่มเกมแรก" → Commit to main

> 💡 commit = "บันทึก snapshot" ของโค้ด ณ ตอนนั้น (ย้อนกลับได้!)
