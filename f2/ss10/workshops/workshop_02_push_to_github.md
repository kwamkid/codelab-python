# 🖥️ W2 · Push ขึ้นฟ้า!

> commit แล้วต้อง push โค้ดถึงจะขึ้นไปอยู่บน github.com (เหมือนอัปรูปขึ้น IG — ใครก็เห็น)

## ขั้นตอน (20 นาที)

1. หลัง Commit → กดปุ่ม **Publish repository** (ครั้งแรก) หรือ **Push origin**
   - ⚠️ เอา "Keep this code private" ออก ถ้าอยากให้คนอื่นเห็น
2. เปิด **github.com/<username>** → จะเห็น repo + โค้ดของหนูแล้ว!
3. ลองแก้โค้ด → Commit → Push อีกรอบ → ดูประวัติใน github.com (Commits)

## 🔁 Workflow ที่ใช้ตลอดไป
```
แก้โค้ด → Commit (บันทึก) → Push (อัปขึ้นเว็บ)
```

> 🎉 ตอนนี้โค้ดหนูอยู่บนเน็ตแล้ว — เปิดได้ทุกที่ทุกเครื่อง!
