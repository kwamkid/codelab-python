# 🌐 Project · Portfolio Online (20 นาที)

> สร้าง "พอร์ตออนไลน์" — รวมผลงาน Level 1-2 ไว้บน GitHub ให้คนเห็น!

## เป้าหมาย

1. อัปโหลดโปรเจกต์ **อย่างน้อย 3 ชิ้น** ขึ้น GitHub (คนละ repo)

2. **Deploy 1 ตัว** บน Replit → ได้ public link
3. แต่ละ repo มีไฟล์ + (HW2) README.md อธิบาย

## ✅ เกณฑ์เสร็จ

- ≥ 1 ตัว deploy แล้วเปิดเล่นได้
