# F2 · Session 10 — 🌐 GitHub + Deploy

> จากโค้ดในเครื่อง → เว็บที่ใช้งานได้จริง! รู้จัก GitHub (เก็บโค้ด) + Deploy (เปิดให้เล่น) — มี Portfolio ออนไลน์ชิ้นแรก

---

## 🎯 วันนี้เด็กจะทำได้
- เข้าใจ GitHub (Google Drive สำหรับโค้ด + ประวัติแก้ไข)
- ติดตั้ง GitHub Desktop + สร้าง repo
- commit + push code ขึ้น github.com
- deploy ผ่าน Replit → public URL

> ✨ Tool ใหม่: **GitHub** + **GitHub Desktop** (GUI ไม่ต้องใช้ command line!)
