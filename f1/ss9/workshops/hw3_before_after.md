# 🔗 HW3 — Debug Before / After (โชว์พ่อแม่)

> ให้พ่อแม่เห็นว่า "ลูกเป็น Debugger แล้ว!" — เปรียบเทียบโค้ดพังกับโค้ดที่แก้แล้ว

---

## ขั้นตอน (5 นาที)

1. เอาไฟล์ **`mini_fix_the_quiz_TEMPLATE.py`** (ตอนยังมี bug) → save เป็น `quiz_buggy.py`
2. แก้ bug ให้รันได้ → save เป็น `quiz_fixed.py`
3. อัปโหลดทั้ง 2 ไฟล์ขึ้น **Trinket** → กด Share → copy link ทั้งคู่
4. ส่งใน **LINE** ให้พ่อแม่ พร้อมข้อความ:

   > "ลูกเป็น Debugger แล้ว! 🐛→✨
   > ลองกดดู — อันแรกรันไม่ได้ (มี bug), อันที่สองลูกแก้แล้วรันได้!
   > before: [link quiz_buggy]
   > after: [link quiz_fixed]"

---

## ✅ เกณฑ์เสร็จ

- มี 2 link: buggy (รันไม่ได้) + fixed (รันได้)
- พ่อแม่กดดูแล้ว → เก็บ screenshot reaction

> 🎯 Programmer ตัวจริงภูมิใจกับการ "แก้ bug ได้" พอๆ กับการเขียนโค้ดใหม่!
