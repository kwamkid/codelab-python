Concept · ตัวแปร + print()
Concept 01 · New today

ตัวแปร = กล่องเก็บของ.

📦

ตัวแปร (variable)

กล่องที่ตั้งชื่อได้ ใส่ค่าอะไรก็ได้ เช่น name = "Aim", age = 11

🖨

print()

สั่งให้โปรแกรมแสดงผลออกหน้าจอ — เครื่องมือแรกของทุก programmer

f

f-string

ใส่ตัวแปรในข้อความ เช่น f"ผมชื่อ {name}" → "ผมชื่อ Aim"

VARIABLES + PRINT
name = "Aim"     # กล่อง name
age  = 11

print(name)      # Aim
print(f"ผมชื่อ {name}
       อายุ {age} ปี")
