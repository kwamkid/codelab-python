# 🎤 Showcase Guide — วันโชว์ผลงาน (ผู้ปกครองชม)

> วันนี้คือวันสำคัญ! เด็กๆ ได้โชว์ของที่ทำมาตลอด 11 คาบ 🏆

---

## 📋 ลำดับงาน (Project · 60 นาที)

| เวลา | กิจกรรม |
|---|---|
| 0-5 | ครูเปิดงาน + เชิญผู้ปกครองนั่ง |
| 5-35 | เด็กผลัดกัน **present เกม Text Adventure** (คนละ 3 นาที) |
| 35-45 | ผู้ปกครองลองเล่นเกมลูก (เปิด Replit link บนมือถือ) |
| 45-55 | 🏆 มอบ **ใบประกาศจบ Level 1** ทีละคน |
| 55-60 | ถ่ายรูปหมู่ + ครูแนะนำ Level 2 (F2) |

---

## 🎤 เด็ก present อะไรบ้าง (3 นาที/คน)

1. **Elevator Pitch** (10 วิ): "เกมผม/หนูเกี่ยวกับ___ จุดเด่นคือ___"
2. **Demo**: เล่นเกมให้ดู 1 รอบ (เลือกทาง → ตอนจบ)
3. **สิ่งที่ภูมิใจ**: บอกว่าทำส่วนไหนเองแล้วภูมิใจ

---

## 🏆 ใบประกาศ Level 1

มอบให้ทุกคนที่เรียนจบ — "CodeLab Python · Level 1: The Coder"
