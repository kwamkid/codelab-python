Concept 01 · New today

Aa

3 ชนิดข้อมูล

⌨

input() — รับค่า

→

casting — แปลงชนิด

int() / float() / str() แปลงก่อนคำนวณ

INPUT + CASTING
age = input("อายุ? ")
# age = "11"  (str!)

age = int(age)   # → 11
print(age + 1)  # 12 ✓
